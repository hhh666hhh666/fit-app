# 切页转场改为「旧页克隆层滑出」，不再依赖 View Transitions

Status: accepted · 2026-10-21

起因：真正的原因在 0.19.2 之后才暴露——**主人设备的 WebView 不支持 View Transitions**（该特性要 Chrome 111+）。`document.startViewTransition` 不存在时，[ADR 0039](./0039-view-transition-tab-slide.md) 的代码一路走兜底「直接切」，于是三帧录屏里中间那帧**整页空白、连底栏都没有**：底栏本来被安排成独立分组钉住，可转场根本没跑，自然也就没有它。

也就是说，此前几轮在 View Transitions 上调的参数、等待时长、底栏成组，在这台设备上全是空转。教训写在最后。

## Considered Options

- **继续修 View Transitions**：否——不支持就是不支持，加兼容判断只能回到「硬切」，等于白做。
- **靠预挂载四页消除空白**：否——uni-app H5 没有预挂载 API，`switchTab` 是唯一挂载途径，来回切一遍会被用户看见。
- **接受硬切、只保留单页微移**：否——主人要的是连续推拉，单页微移看不出方向关系。
- **克隆旧页做滑出层（选定）**：切换前把当前页正文 `cloneNode(true)` 塞进一个 fixed 覆盖层，切换后整层滑出，新页同时从另一侧滑入。纯 DOM ＋ WAAPI，不依赖任何新特性。

## Consequences

- **白屏被顺手解决**：克隆层铺上去之后才 `switchTab`，新页挂载的几十到几百毫秒里**屏幕上是旧页在挡着**。之前所有版本（动画、预热、保活）都没解决的那一帧空白，现在被旧页遮住了。
- **底栏钉住**：底栏不在正文里（它是 `.xx__bottom` 这个 fixed 兄弟节点），克隆体只含 `__body`；再给四个页面的 `__bottom` 加 `z-index: 20` 压住克隆层（`z-index: 10`），转场期间底栏纹丝不动。
- **滚动位置要补偿**：页面滚动在外层容器上，克隆体从顶部开始，所以读一次祖先的 `scrollTop`、给克隆体 `translateY(-scrollTop)` 才对得上当前视口。（2026-10-22 改为按 `getBoundingClientRect()` 绝对定位，见下方修订。）
- **代价**：克隆成本随 DOM 增长（日志页几百节点，实测无感）；`canvas`（趋势图）克隆出来是空白的，滑动中一闪而过；旧页的图片会以缓存地址重新渲染，正常。
- **兜底**：动画 `finished` 与一个 `SLIDE_MS + 250ms` 的定时器双保险摘层——省电模式跳过动画时，绝不能让覆盖层留在屏幕上。
- **新页入场不再设短上限**：`playTabEnter` 轮询到元素连进文档就滑（最多等 2 秒）。不再有「挂载慢就不播」的规则——那时候旧页多半已经滑走，正是它该出现的时刻。
- **本地可验**：克隆层是普通 DOM，headless 里能看到层的存在、动画 `playState`、`z-index`、克隆的是哪个类，以及到点是否被摘掉。（View Transitions 则完全验不了。）

## 踩过的坑（记下来别再犯）

1. **不要凭文档就给主人设备上新特性**：先确认 `typeof document.startViewTransition` 在真机 WebView 里存在，再谈方案。这一轮代价是连着五个版本。
2. **headless 里的「验不出来」要先怀疑工具链**：最后两次本地检查其实是本地静态服务早就挂了，打开的是 404 页面（`location.hash` 为空、`uni-page` 数为 0）。看到 0 就该先确认基线，而不是继续读结论。

## 修订（2026-10-22）：主人反馈「切页总感觉哪里不舒服」

实测出三处，均已修，方案本身不变：

1. **两层不同步**：克隆层一点就滑，新页要等 `onShow` ＋ 一帧才起步，中间几帧新页已在原位、又被透明克隆层叠着——重影后再「弹」一下。改为克隆层带 `$app-canvas` 底色、铺好后先不动，由 `playTabEnter` 在新页就绪的同一帧放行（超时 400ms 自己滑）。
2. **首页底部一大块硬切**：提示行／训练横幅／「开始训练」原本和 tabbar 一起钉在 `__bottom` 里，正文在滑、它们瞬间出现或消失。拆出 `.home__dock` 随正文滑，只钉 tabbar；克隆块改为按视口位置绝对定位，滚动补偿随之取消。
3. **指示条从没滑过**：`FtTabBar` 判了 `ref` 的 `animate`，而 uni 的 `ref` 是组件实例，一直提前 return；首访时 `enterSeq` 在挂载前就加过，watch 也看不到。修好后从**真实来源格**起步（跨格跳也对），时长缓动与正文一致。
