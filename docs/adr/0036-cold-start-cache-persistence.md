# 冷启动也读缓存：数据快照落 localStorage、餐照落 IndexedDB

Status: accepted · 2026-10-21

本卡**收窄** [ADR 0035](./0035-client-cache-and-invalidation.md) 的一条取舍（「冷启动仍全量拉取，不落 storage」），其余口径不变：仍是写后失效、按域作废、不设 TTL、时间类按自然日分区。

起因：主人追问「杀后台重进后也不加载」。ADR 0035 的缓存活在 JS 运行时里，进程一死就没了，冷启动仍要 7~8 个请求。这一层的取舍是：**要不要把缓存写到硬盘上，让下一次启动直接拿来用**。

## Considered Options

- **不落盘（ADR 0035 原取舍）**：否——冷启动是唯一的「每次都白等一轮」的场景，而它恰好是缓存本来能覆盖的一段。
- **hydrate 后再静默校验一轮（stale-while-revalidate）**：否——页面 `ref` 拿到的是缓存里的**旧对象**，替换缓存不会驱动重绘，要额外做一套事件通知让四个主页面重取；改动面从「一个文件」扩散到「每个主页面」，而且「先显示旧值再跳变」本身可能被感知为一闪。代价换来的是防住「本机不知情的外部改动」——而本项目只有手机 App 一个写入端（[ADR 0001](./0001-self-use-tool.md)），这种情况没有来源。
- **整个缓存全量落盘**：否——`/diet/trend`（全量历史趋势）与 `/body`（含全部体重／围度序列）随记录线性增长，同步写 localStorage 会掉帧，且迟早逼近 5 MB 上限。
- **数据与照片都进 IndexedDB**：否——一套接口更干净，但 IndexedDB 是异步的，`read()` 里就得多一道「等 hydrate 就绪」的闸门；忘了 await 的症状是「偶尔又多拉一轮」，属难查的那类。而数据快照只有几十 KB，同步读写能换来启动路径零时序问题。
- **数据快照落 localStorage（白名单小接口）＋ 餐照落 IndexedDB，启动不校验**（选定）。

## Consequences

- **两条存储通道，职责按体积分**：`api/cache.ts` 管数据快照（localStorage，`fitapp_cache_v1:<username>`，同步读写）；`utils/photo-cache.ts` 管照片 blob（IndexedDB `fitapp-photos`，异步按需读）。
- **白名单只收首屏用得到的小对象接口**（日志首屏、月度汇总、统计、当日饮食、设置、计划、周表、动作库、累计、食物计数、存储占用、识别用量）。**刻意排除** `/diet/trend`、`/body`、`/foods`、`/combos`、`/workouts/{id}`：它们要么随数据量增长，要么只有进子页才用得到。单条超过 64 KB 或整份超过 512 KB 就不写（宁可少缓存，不阻塞主线程）。
- **启动零时序**：`App.vue` 的 `onLaunch` 里 `hydrateCache()` 同步灌回内存，页面 `onShow` 一调就命中，不需要 await 任何「就绪」。
- **三道闸防串味**：快照带结构版本 `v`、构建版本 `__APP_VERSION__`（由 `vite.config.ts` 从 `package.json` 注入）与条目日期 `day`。构建版本不匹配就**整份丢弃**——后端 VO 加了字段、旧缓存塞给新代码是最难查的一类错；`day` 不匹配的条目在落盘时就被剪掉（跨零点的窗口重算）。键里带 username，换人读不到上一个人的数据。
- **照片磁盘预算 128 MB**（内存那 64 MB 是另一回事）：按「最久未用」淘汰，不做 UI。命中磁盘后放进内存 LRU，`<img>` 仍只认 objectURL。照片与构建版本无关，所以清快照时不动它；但**登出 / 401 会把磁盘也清掉**（不能把上一个人的照片留在手机上）。
- **不做「本机缓存占用」界面**：想看就清缓存，不需要一个数字来管理一张自用手机。真要清，登出即可。
- **仍然存在的能力上限**：这一步只消除「数据到达前的空窗」。WebView 解析执行主包、挂载 Vue 的那几十~几百毫秒照样在，真要连这段也砍掉只能换原生渲染或首屏内联骨架——那是 [移动端流畅度优化](../todo/2026-10-20-TODO-移动端流畅度优化.md) 与ADR 0034 的地盘。
- ⚠️ **IndexedDB 可能不可用**（存储被禁／隐私模式）：`openDb()` 失败时静默降级为「只有内存缓存 + 每次重拉」，不抛错、不弹窗。
