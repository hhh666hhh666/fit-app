# 认证：注册登录（不含改密／找回／风控）

Status: accepted

做完整但最小的注册与登录：用户名＋密码注册、登录发 JWT。骨架里认证管道已就绪（签发工具、拦截器、白名单插槽），补用户表、注册／登录接口与前端页面即可。明确收窄：不做改密、找回密码、邮箱／手机验证、图形验证码与注册限流。

## Considered Options

- **单口令（配置里一个密码）**：否——需求打磨拍板要注册登录，为「将来可能给亲友用」打底。
- **完整注册体系（注册／改密／找回／验证）**：收窄——改密「暂时不做」（明确拍板）；其余不做。
- **不做认证（裸奔）**：否——公网部署下任何人都能改数据，风险与成本不成比例。
- **注册＋登录的最小完整集**（选定）。

## Consequences

- 注册入口开放、无风控：任何人知道网址即可注册——自用级有意接受（见 [ADR 0001](./0001-self-use-tool.md)）；将来对外时须补风控（已知安全债）。
- 无改密／找回：忘记密码暂时只能改数据库。
- 认证复用骨架既有 JWT 方案（拦截器 ＋ 用户上下文），不引入新依赖。
