# 设计语言改为「晴窗」：冷调浅底、苹果式玻璃、橙色只给动作，训练入口嵌进底栏中间

Status: accepted · 2026-10-24（落地按批次推进，进度见 `docs/todo/` 的设计语言重构待办）

2026-10-11 定稿的「训练日志」设计语言（冷调纸感 · 墨黑 · 荧光笔单一信号色）用下来有三个问题：缺质感和情绪；页面之间不统一（各页自绘顶栏、卡片、列表行，散落 63 处写死颜色）；按压、弹层、数字变化缺反馈。这次**整体替换**，不在旧语言上演进；新语言叫「晴窗」，取「晴空的冷调浅底 ＋ 一扇扇玻璃面板」。旧名「训练日志」从此只剩领域含义（已完成训练的历史视图，见 `CONTEXT.md`）。

定稿依据是 2026-10-23~24 的九轮样稿（私有 Artifact，一次性参照，不入库），最终选「壬」。

## 定了什么

**视觉**

- **底**：以 `rgb(239, 244, 249)` 为中心的冷调浅蓝灰竖向渐变，角落叠几团浅蓝光晕和一团极淡的桃色光晕——给玻璃底下留可透的东西。只做浅色，不做深色模式。
- **面板**：苹果式玻璃——半透白底 ＋ 背景模糊与饱和 ＋ 白色亮边 ＋ 极细外描边 ＋ 柔和投影；大圆角（卡片 24px 档）。
- **文字**：苹果系冷中性灰，正文 `#1D1D1F`、次要 `#6E6E73`；12px 以下的字一律过 4.5:1。
- **强调色**：橙色，**只给动作**——开始训练、完成本组、继续训练、PR、当前组。导航选中态、装饰不用橙。
- **字体**：中文走系统字体，**只用 400／700 两档**（安卓各家中文字体中间字重不可靠）；数字与拉丁字符用自托管子集化的 Nunito（700／800），`kg`、`×` 这类单位符号也走数字字体。
- **图标**：自带 SVG 线性图标，一套线宽；餐次入口是「浅色底 ＋ 同色系图标」，六个入口各占一个色相（记体重为草绿，加餐为饼干）。
- **营养素**：「名称 ＋ 数值／目标 ＋ 进度条」的条形，不用同心环。

**结构与交互**

- **底栏**：悬浮玻璃胶囊，五等分：首页、日志、**中间训练按钮**、统计、我的。胶囊顶边正中是**真凹口**（带圆角过渡），按钮嵌在凹口里。选中项＝深色字 ＋ 填充图标 ＋ 浅色胶囊底，这块胶囊底就是 ADR 0037 那条会滑动的指示条换皮，滑动时跳过中间格。
- **训练入口全局化**：「开始训练」不再是首页底部的一整行按钮，而是底栏中间的橙色圆钮（哑铃图标，不用「＋」——这个 app 里「加」的东西太多），**四个主页面都能直接开练**；选计划弹层随之从首页挪进底栏组件。
- **训练进行中**：中间圆钮变成「继续」（播放图标），外圈绕**一颗**流星；首页的「训练进行中」横幅**取消**。设置页里流星／流光／关闭三选一保留，作用对象从横幅改成这颗圆钮的外圈。
- **会话页**：当前动作标签＝白底 ＋ 橙色描边；「结束训练」降为灰色次级按钮；底部汇总条改成和底栏同款的悬浮胶囊——页面上唯一的焦点是橙色的「完成本组」。
- **基础组件**：先抽 `Ft*` 组件（页头、卡片、列表行、按钮、底部弹层、空状态、数字展示、图标），各页改用后再统一换皮。

**技术口径**

- token 继续是 `frontend/src/uni.scss` 的 SCSS 常量，**不迁 CSS 变量**（不做深色，用不上运行时切换）。
- 移除 wot-design-uni（全站只用了 `wd-icon`）。
- 凹口用 `clip-path: path()` 裁玻璃层，亮边与投影用同一条路径另画（投影不能挂 `filter` 在玻璃的父级上，否则背景模糊失效）。
- 新增「写死颜色」守卫脚本 ＋ CI 同名 job：地基阶段只告警，全部页面换完后转硬失败。
- 切页机制（ADR 0037~0040）不动。

## Considered Options

- **在「训练日志」上演进**：否——主人要的是换风格，不是打磨；旧语言首日定稿，没被真实使用检验过，现在换代价最低。
- **甲 · 暖调柔和**：暖白底、大圆角、柔和阴影、橙色强调。**布局与组件被保留下来**（「以甲为准」），暖白底被换掉。
- **乙 · 精致运动**：冷白底、压缩体大数字、电光蓝、分段刻度。否——利落但冷硬，做不细容易像模板。
- **丙 · 质感极简**：灰白底、细体大数字、低饱和鼠尾草绿、同心环。否——太克制，同心环可读性差。
- **丁 · 天蓝玻璃**：天蓝渐变 ＋ 玻璃拟态。初版太深；调浅后仍是蓝色主导，否。
- **戊 · 液态玻璃**：暮色石板蓝 ＋ 山脊剪影 ＋ 白字玻璃。否——底色深，下半屏白字对比度要靠深色玻璃硬托；胶囊控件与悬浮底栏的语汇被晴窗吸收。
- **己 · Win11 Fluent**：Bloom 光晕 ＋ 亚克力 ＋ 8px 小圆角 ＋ 任务栏式底栏。否——Segoe UI 不能随网页分发，安卓上「Win11 味」必然打折。
- **庚 · 甲 × 苹果玻璃**：晴窗的直接前身；会话页两块近黑色块抢了「完成本组」的焦点，由辛修正。
- **辛 · 庚 ＋ 细节 ＋ 底栏**：首页保留整行「开始训练」、进行中用横幅。被壬取代——底部三层叠太厚，且只有首页能开练。
- **深色模式／深色主题**：否——用不上，还要把 token 迁成 CSS 变量。
- **底栏全宽贴底**：否——安卓用户熟悉，但和玻璃面板的语汇不统一。
- **中间按钮用「＋」**：否——含义不明（加食物？加身体档案？）。
- **中间按钮「悬浮 ＋ 光圈」代替真凹口**：实现更稳，但主人要真凹口；先按真凹口落地，真机出问题再退回光圈。
- **进行中保留首页横幅**：否——圆钮已经承担「继续」，横幅只剩重复信息。
- **双流星**：否——绕一颗圆钮时两颗显得乱，减为一颗。

## Consequences

- **性能风险**：每块面板都做背景模糊，安卓 WebView 可能掉帧。第一批落地后先在真机测；不行就提高面板不透明度、减小模糊半径，最坏退回「不模糊的半透白」。
- **凹口风险**：`clip-path: path()` 加背景模糊在 Chromium 支持，但要真机确认；失败退回「悬浮 ＋ 光圈」。
- **等宽数字**：Nunito 是否带 `tnum` 要实测；计时器每秒跳，宽度不等会左右抖。
- **流星组件要改**：`FtMeteorTrace` 现在画的是绕横幅的双流星，要改成绕圆钮的单流星；流光档同样要重画到圆钮外圈。
- **「开新的」改为长按圆钮**：ADR 0020 规定有进行中会话时点「开始训练」先弹「继续上次／开新的」。晴窗里进行中时圆钮点一下＝直接继续；**长按**才弹出原来那个二选一（文案沿用）。否掉的两种：每次点都先弹框（回会话多一步，违背组间 30 秒）、会话页加「放弃并重开」（推翻 ADR 0011）。
- **交互口径变了**：训练入口从首页变成四个主页面通用，首页不再有进行中横幅——`docs/design/前端.md` 里描述首页底部 dock、横幅与「开始训练」的段落要随落地改写。
- **推行**：地基（token、字体、图标、基础组件）→ 按页四批（①四个主 tab ＋ 会话 ＋ 汇总 ②饮食一组 ③计划／动作库／周安排 ④其余）；批次之间新旧风格混搭可接受。地基发 0.22.0，四批依次到 0.26.0。
- **收口**：全部换完后用 `impeccable document` 从 `uni.scss` 派生 `DESIGN.md`；`uni.scss` 头注释改名「晴窗」；根目录 `PRODUCT.md` 已过时，一并刷新。
- **样稿不入库**：Artifact 只是一次性参照，不链进文档、不当规格；落地以 `uni.scss` 与组件代码为准。
