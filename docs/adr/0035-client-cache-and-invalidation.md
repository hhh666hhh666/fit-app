# 客户端数据缓存：写后失效、按域作废，不设 TTL

Status: accepted · 2026-10-21

起因：主人反馈「切一次页面，页面上的数据就刷新一次，看起来不流畅」。实测排除后端之后，问题在结构：四个主 tab 之间用 `uni.reLaunch`（关掉所有页面、重建目标页），而每个页面都在 `onShow` 里无条件全量取数——首页一次 7 个请求、「我的」页 8 个，切一次 tab 就重来一次；`api/request.ts` 里没有任何缓存或并发去重，后端也没有 ETag／版本号／条件请求可用。

本卡定的是「客户端怎么记住已经拿过的数据、什么时候该忘掉」。它不改导航形态（仍是 `reLaunch`），也不要求后端配合。

## Considered Options

- **照旧每次请求，只补骨架／转场**：否——请求本身才是白屏窗口；骨架只能把等待变成「有反馈的等待」，遮不掉等待。
- **缓存先显示 ＋ 后台静默校验（stale-while-revalidate）**：否——本项目只有手机 App 一个写入端（[ADR 0001](./0001-self-use-tool.md) 自用、N=1），本机写操作是唯一变更源，后台校验等于每次切页仍发一个请求，还要处理「校验回来数据变了」的二次重绘。
- **统一 TTL（如 10 分钟）**：否——会在「什么都没改」的时候突然重载，与主人诉求正相反；到期时刻也不可预期，出问题时无从解释。
- **改 `tabBar` ＋ `switchTab` 保活**：本轮否——保活能连滚动位置一起保住，但要动 `pages.json`、自绘 `FtTabBar` 与全站路由约定，且 H5 下「自定义 tabBar ＋ `switchTab`」的保活行为需真机实测。风险面远大于收益，留作后路（见下方 TODO）。
- **全域清空失效**：否——删一条日志会让首页 7 个请求全部重来，优化效果归零。
- **精确到 key 失效**：否——全仓 20+ 个写操作点，漏一个就是「改了不生效」，这类 bug 极难发现。
- **写后失效 ＋ 按域作废 ＋ 无 TTL（时间类按自然日分区）**（选定）。

## Consequences

- **缓存挂在请求层之上**（`api/cache.ts`）：键＝URL＋参数，每条记一个域——训练／计划／饮食／身体／食物。写入成功后按域整组作废，所以规则只有一条：**域内任一处改动 → 域内全部重取**。
- **缓存保存的是 `unwrap` 之后的同一个对象引用**：页面拿到的是同一个对象，重复赋值在 Vue 里是 no-op，因此缓存命中不会引起任何重渲染。
- **按域失效是粗的，代价是知道的**：改一条饮食会连带作废同域的全部缓存（含食物组合列表）。取域而舍 key，是因为域的边界比字符串容易记——漏不掉的收益大于多取几次的成本。
- **不设 TTL，唯一的时间失效是按自然日分区**：每条缓存记下写入时的本机日期，跨零点后自动落空。必须这样做的是时间窗口类接口（`/stats` 的「本周／本月」、`/workouts/month-summary` 不传月份时的当月口径），否则第二天早上会看到昨天那段区间算出来的数——**静默错，且没有任何提示**。
- **分页列表只缓存首屏**（`offset = 0`）；续页、带搜索词的列表、相册列表、识别明细、导出都不进缓存，避免「第 3 页被删过一条」这类对不齐。
- **照片不进这套缓存**：`<img>` 带不了鉴权头，照片走的是 `fetch → blob → objectURL`，缓存单位是 blob，按**字节 LRU、64 MB 上限**另存于 `utils/photo-cache.ts`（单张原图上限 10MB，按张数算会估不准内存）。页面卸载不再 revoke——`releasePhotoUrl` 已删除，只由 LRU 挤掉、被换图／删图、或登出清空。
- **换人用就清空**：401、登出、换账号一律清掉整份缓存（含照片），否则会残留上一个人的数据。
- **下拉刷新是逃生门**：四个主 tab 开 `enablePullDownRefresh`，下拉＝清空全部数据缓存后重载。缓存层出任何问题时，主人都有办法拉最新。
- **明知的代价**：页面仍会被 `reLaunch` 销毁，滚动位置与日志页选中月份不保留；冷启动仍是全量拉取（不落 storage）。两者都另案，见 `docs/todo/archive/2026-10-21-TODO-切页体验后续.md`。
- ⚠️ **新增写操作必须走 `mutating(域, …)`**：这是本方案唯一靠纪律维持的地方——直接调 `request.post` 而不作废缓存，症状是「改了不生效」，且只在切页之后才看得出来。
