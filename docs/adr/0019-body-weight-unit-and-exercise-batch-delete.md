# 身体体重单位偏好与动作库批量下架

Status: accepted

身体档案体重内部统一保存为 kg，并在设备端保存斤／千克查看偏好；首次默认斤，斤显示 1 位小数、千克显示 2 位小数，输入超出当前单位精度直接拒绝。动作库仅允许对自定义动作执行长按多选下架，预设动作不可删；下架使用既有归档语义，历史训练与计划快照继续保留。

## Considered Options

- **所有训练重量也切换斤／千克**：影响训练日志、计划目标、总容量、PR 与接口语义，超出本次身体档案需求范围。
- **每条身体记录保存录入时单位**：历史记录会混合单位，切换与统计复杂且容易误读。
- **动作库物理删除或联动删除历史**：会破坏动作弱引用和历史展示，造成不可逆数据丢失。
- **只支持逐个删除或新增独立编辑按钮**：与训练日志已有长按多选模式不一致。
- **内部统一保存 kg + 设备级偏好转换**（选定）：避免来回切换产生累计误差，复用现有动作归档生命周期。

## Consequences

- 身体体重列需要以 2 位小数保存，已有数据保持数值不变。
- 单位偏好仅保存在当前设备，不做账号级同步。
- 动作批量接口先整体校验自定义动作归属，再事务性批量下架。
- 身体档案整体覆盖更新必须显式写入 null，才能让主人清空不再保留旧值。
