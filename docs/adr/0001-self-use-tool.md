# 定位：自用工具，公网部署

Status: accepted

fit-app 是个人自用（N=1）的健身训练记录工具：验收标准是「自己用得爽」，不背公开产品的包袱（不做注册风控、内容审核、运营）。数据模型从第一天带用户维度，为「将来给亲友用」留低成本余地。它同时要部署到公网——自用不等于只在局域网：手机 App（壳）需要加载线上网页，训练现场与在外场合都要能访问；复用现有域名与服务器体系。

## Considered Options

- **公开产品**（对公众开放注册与运营）：否——注册风控、内容合规、运营都是持续成本，且与主线项目争精力；将来若真要公开，需重新评估并补风控。
- **纯局域网／本机自用**：否——手机 App 形态与「随时访问」诉求都要求公网部署。
- **亲友小圈子**：不单独取舍——数据带用户维度＋注册登录（见 [ADR 0003](./0003-register-login-auth.md)）已覆盖，升级不需要额外决策。
- **自用（N=1）＋公网部署＋留多用户余量**（选定）。

## Consequences

- 注册入口开放且不做验证码／限流：任何人知道网址即可注册——属有意接受的取舍（见 [ADR 0003](./0003-register-login-auth.md)），将来对外时必须补，记为已知安全债。
- 数据带用户维度：将来「给亲友用」不需要数据迁移。
- 公网部署下认证必须兜底（ADR 0003）。
