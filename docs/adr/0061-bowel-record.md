# 排便记录：单独一个小模块，入口放在身体页最底部

Status: accepted · 2026-11-21

主人要记大便、小便的时刻，并且能看统计。这是本项目第一次记「吃喝」和「身体测定」之外的身体事件。

## 决策

1. **记什么**：一笔排便记录包括大便还是小便、时刻、可选的备注；大便可以另选布里斯托形态（1–7 型，选填）。颜色、量这些不记。
2. **入口**：放在身体页最底部的一行「排便记录 ›」，不进首页，也不进底栏。页里顶部是「大便」「小便」两个按钮，点一下就按现在的时刻记一笔，记完可以改时刻、补形态和备注。
3. **统计**：每天大便、小便各几次的柱状图，平均间隔，一天里集中在哪几个钟点，大便形态的分布。
4. 删掉的排便记录**进回收站**；**外部 agent 能读到**。

## Considered Options

**放在哪**

- **并进身体档案**：否。身体档案是体重、围度的定期测定，一条记录有六个测定项；排便是一天好几次的事件，两者的形状完全不同。
- **放首页或饮食页**：否。主人要求不显眼。
- **身体页最底部的单独一行**（选定）。

**大便记多少细节**

- **再加颜色、量、用时**：否。录的人嫌麻烦，统计也用不上。
- **只加布里斯托形态，选填**（选定）。

**进不进外部 agent**

- **不进**：否。这是身体情况的数据，正是 agent 分析需要的；它和日记不一样，不会写私事。
- **进**（选定）。

## Consequences

- 新建一张表、一组接口和一个页面；回收站多一类可恢复的记录；外部 agent 接口多一类数据。
- 术语表加「排便记录」。

## 修订（2026-11-21）：入口挪到首页

主人要求把入口挪到首页「今天吃了」卡下面那排入口里。那排入口改成一页六格、可以左右滑动换页（下面有页码点），第一页仍是三餐、加餐、饮水、记体重，排便放在第二页（卷纸图标，暖灰褐的 `$meal-bowel-*`）。身体页最底部那一行撤掉。不显眼的要求照旧满足：第一页看不到它，要滑一下才有。
