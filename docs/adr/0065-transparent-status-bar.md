# 透明状态栏：页面画到状态栏底下，壳经 JS 桥把状态栏高度交给 H5

Status: accepted · 2026-11-23

0.1.8 的壳把状态栏染成页面渐变顶端的纯色（`$app-canvas-top`），但页面右上角有一团光晕，纯色状态栏接不上，看着像顶上多了一条色带（2026-11-23 主人反馈）。改成状态栏透明，页面渐变一直铺到屏幕顶；导航栏不动，仍是页面底色。

## 决策

1. **壳（0.1.9 起）**：关掉系统对状态栏的自动避让，状态栏透明、图标深色；导航栏、键盘仍由壳给 WebView 让出来（软键盘改为显式 `adjustResize`）。
2. **状态栏高度由壳告诉 H5**：`window.FitShell.statusBarHeight()`（CSS px），高度变了再推给 `window.__ftSetTopInset`。H5 写进根上的 `--ft-top`。
3. **各页顶部留白一律用 `$safe-top`**（`frontend/src/uni.scss`）：先读 `--ft-top`，没有（旧壳、浏览器）就回落 `env(safe-area-inset-top)`。不再直接写 `env(safe-area-inset-top)`。
4. **顶部渐隐带**：拿得到高度时，在 body 上垫一条和页面底同一层渐变的渐隐带，盖住状态栏那一段再往下淡出；内容滚上去在那里消失，不和时钟、信号图标叠在一起。弹层遮罩仍盖到屏幕顶。
5. **黑底层换白色图标**：全屏看图、头像裁剪开着时经 `FitShell.setStatusBarIconsLight(true)` 换白色，关掉换回。

## Considered Options

- **继续染纯色，换成更接近光晕的颜色**：否。光晕只在右上角，纯色只能对上一边，切页、滚动时还会露出接缝。
- **透明后靠 `env(safe-area-inset-top)`**：否。安卓 WebView 上它通常是 0，内容会直接钻进时钟底下。
- **透明后各页写死一个顶部高度**：否。状态栏高度因机型、挖孔而异，写死不是留多了就是盖住。
- **系统栏颜色由 H5 随页面动态设置**（2026-11-07 UI 走查时的方案乙）：否。要的是「看不见状态栏这一条」，透明一次到位，不用每页去配颜色。
- **壳给高度、H5 留白、加顶部渐隐带**（选定）。
- **导航栏也一起透明**：这次不做。三键导航那一条和页面底色几乎看不出差别，透明后底栏、输入框都要重新避让，收益小、风险大。

## Consequences

- 改了壳，要重打 apk（0.1.9）并在手机上覆盖安装一次；前端改动照常经自动更新下发。新前端在旧壳上拿不到高度，表现和改之前一样。
- 新加页面、全屏层的顶部留白必须用 `$safe-top`，写成 `env(safe-area-inset-top)` 在 App 里会被时钟压住。
- 新加黑底全屏层要调 `holdLightStatusIcons()`（`frontend/src/utils/statusBar.ts`），否则状态栏图标在黑底上看不见。
- `FitShell` 多了两个口子，都是无害的（读高度、换图标深浅），仍守「不放读写数据的能力」。
