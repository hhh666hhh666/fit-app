# 识别详情显示价格：只算 DeepSeek，按北京时间分高峰与空闲

Status: accepted · 2026-11-09

主人要在识别详情里看到这一次调用花了多少钱，以及钱是怎么算出来的；目前只算 DeepSeek 的模型，并且要考虑峰谷价。这推翻了 [ADR 0018](./0018-food-label-photo-recognition.md) 的「不显示费用」，范围只在**识别详情页**——「我的」页的用量小卡和明细列表仍然只显示 token 与次数。

价目来自 DeepSeek 官方定价页（2026-11-09 读取），每百万 token、人民币：`deepseek-flash` 高峰价缓存命中 0.04 元、未命中 2 元、输出 8 元，空闲时段一律半价。高峰时段是北京时间周一至周五（不含中国法定节假日）9:00–12:00、14:00–18:00，其余时段（含周末、节假日全天）都是空闲。

## Considered Options

**在哪算**

- **前端算**：否——价目和节假日表放在前端，App 内置的页面不一定是最新的，算出来的数会因版本不同而不同。
- **识别时算好存进库**：否——这样已有的记录都没有价格，而且算法一错就改不回来。
- **详情接口按记录现算，价目表带生效日**（选定）。价格调整时往表里加一版并写上生效日，不改旧版，老记录仍按当时的价算。

**「法定节假日」怎么认**

- **只认法定的那十几天**：否——官方原话是「不含中国法定节假日」，按大家理解的「放假」来算更贴近实际。
- **按国务院每年的放假安排里的放假日**（选定）：2026、2027 两年已录入。调休补班的周六周日仍按周末算空闲，因为官方只说周一至周五。没录入的年份只按周末判断，详情页上会写明。

**按哪个时刻判断峰谷**

- 取**请求发出的时刻**：记录是调用结束后写的，往回减掉耗时。

**别家的模型**

- 不算，详情页写明「目前只计算 DeepSeek 的模型」。

## Consequences

- 新增 `DeepSeekPricing`（价目表、放假日表、峰谷判断、分项计算），详情接口 `GET /api/food-recognition/logs/{id}` 多带 `price`。
- 详情页加「价格」一节：合计（不到一元时另给「约多少分」）、高峰或空闲、三项明细（token × 单价）、判断时段的理由与时刻、价目出处。
- 是按官方价目的**估算**，以 DeepSeek 账单为准。官方没写图片 token 和思考 token 怎么计费，这里按惯例把它们分别算进输入和输出。
- **每年要补放假安排**（国务院一般在 11 月公布下一年的），DeepSeek 调价时要加一版价目，见 `docs/todo/2026-11-09-TODO-餐次AI识别后续.md`。
