# 计划目标重量与会话页组次流程（预填 / 点勾 / 自动切换）

Status: accepted

计划的动作编排增加「目标重量」，与既有目标组数、目标次数构成三层目标（均可不设）。会话页据此把「开始训练」的动作从「空表起步、勾一组补一行」改为「按目标预填、点勾即完成」：目标组数铺行、重量与次数预填为默认值；完成一组只标记完成（「加一组」是独立按钮）；一个动作的全部组完成后自动切到下一个动作。动机是省掉每次进训练页的重复填数，并把「一组做完」与「再来一组」两个决定分开。

## Considered Options

- **维持「勾一组自动补一行」**：否——补行是拿「完成」兼职「加组」，页面上「自动补行」与「加一组」按钮两个入口做同一件事，语义含混；且每次都要重填重量/次数。
- **默认值用「上次记录」兜底（目标没设重量时预填上次值）**：否——默认链只认计划目标一条数据流；隐式来源会让「预填值从哪来」不可预期。
- **加重量目标但不预填（仍手填）**：否——没省掉主人提出的重复填数痛点。
- **目标驱动预填 ＋ 点勾完成 ＋ 全组完成自动切换**（选定）。

## Consequences

- `plan_exercise` 加 `target_weight DECIMAL(5,2)`（V9）；计划编辑弹层三项：组数／每组次数／重量；计划行摘要「目标 4 组 × 8 次 · 60 kg」。
- 会话页变为多动作页：进入时全部动作进场（各自预填），「更换」＝手动切下一动作（原为占位）；底部「本次 X 组 · 总重」跨动作累计；结束训练一次提交全部动作的已勾组（`WorkoutCreateDTO.blocks` 本就是数组，提交侧零改动）。
- 未设目标的动作：1 行起步、不预填、不参与自动切换（没有「完成」信号可数）；自由训练行为不变。
- 三层目标只是**预填默认值**，训练中怎么改都不回写计划（scope #9）。
- 本次未做：临场增删动作（「添加动作」仍为占位）、组撤回、回看上一动作 → 见 [会话页临场编辑能力待办](../todo/2026-10-12-TODO-会话页临场编辑能力.md)。

> ⚠️ **后续（2026-10-13）**：会话页的切换方式被 [ADR 0010](./0010-session-free-switch-and-early-finish.md) 扩展——由「全组完成自动切下一动作 ＋『更换』切下一个」改为**动作自由切换**（顶部动作分段条，可任意跳转），自动切换改为「切到下一个**未完成**动作」；并新增「结束训练前未完成校验」。本卡其余结论（按目标预填、点勾仅完成、目标不回写计划）不变。

> ⚠️ **后续（2026-10-17）**：本卡的「三层目标」被 [ADR 0027](./0027-plan-per-set-targets.md) **收窄**——目标次数与重量改为**每组各一份**（子表），本卡的「按目标预填」改为「第 i 行取第 i 组的目标」。本卡其余结论（目标只是预填默认值、训练中改动不回写计划、点勾仅完成）不变；循环组内的推进顺序另见 [ADR 0028](./0028-plan-circuit-groups.md)。
