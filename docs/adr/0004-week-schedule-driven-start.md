# 训练开始：周安排驱动（含计划名自定义与「休息」语义）

Status: accepted

主页「开始训练」不再询问「练什么」——按**周安排**自动匹配当日：周安排＝一周七天各挂一个计划或「休息」（同一个计划可重复挂多天，如周一、周五都练）。匹配到计划就直接按计划开始记录；当天是「休息」或还没设置过，则以弹层告知并给出出路——**休息日**弹层保留「自由训练」入口（想临时练不受挡），**未设置**弹层引导去「训练安排」设置。同时撤除主页原「按计划开始」入口（双入口语义含混，实际使用中对「点开始训练为何直接进页面」产生过疑问）。计划名一律由用户自定义（如「胸 & 三头」「背 & 二头」），全站唯一的固定词是「休息」。

## Considered Options

- **每次开始弹「选择计划」层**：否——把这个决定留给用户每天做一次，违背「30 秒记录动线」的顺手原则。
- **保持双入口**（「开始训练」＝自由练 ／「按计划开始」＝选计划）：否——语义隐晦，实际使用时产生过疑问。
- **进入记录页后再选计划**：否——空白起步观感弱，且关键决定被埋进第二屏。
- **周安排驱动（自动匹配 ＋ 弹层兜底）**（选定）。

## Consequences

- 计划模型分两层：**计划**（内容：动作编排）＋**周安排**（哪天练哪个）；新增「训练安排」设置页（七天各挂计划或休息）。具体落库形态（独立周表 vs 计划表加字段）在实施设计时定。
- 「休息」显式化：想临时练走弹层里的「自由训练」；记录页内仍可随时换动作、加动作。
- 主页底部小字从「按计划开始」变为「今天 · ＜计划名＞」；休息／未设置各有一套弹层文案（同结构）。
- 设计稿：`week-setup` / `home-plan` / `rest-sheet`（`.workbuddy/stitch/screen/`，一次性参照）。
