# 账号页：昵称、改用户名、改密码与注销

Status: accepted · 2026-11-06

之前账号只有用户名和密码，注册以后什么都改不了（[ADR 0003](./0003-register-login-auth.md) 定的是改密「暂时不做」）。现在新增一个二级页「账号」，从「我的」页页头进入，里面有：头像与历史头像（见 [ADR 0051](./0051-photo-limit-50mb-and-avatar.md)）、昵称、改用户名、改密码、退出登录、注销账号。**改密这一项取代 ADR 0003 里「不做改密」的那部分**，找回密码和验证码风控仍然不做。

## Considered Options

**放在哪**

- **塞进现有「设置」页**：否——「设置」放的是怎么用这个 App（压缩档、饮食目标、动效），账号放的是这个账号是谁，混在一起两边都不好找。
- **点「我的」页页头进入新的「账号」页**（选定）。退出登录也从「我的」页底部挪进来。外部 agent 那一页还有接口文档，不只是令牌，所以留在「我的」页。

**昵称**

- **不做昵称，只显示用户名**：否——用户名只能用字母、数字和下划线，主人想显示中文名。
- **昵称 1～20 个字符，什么字都行，可以重名，清空就算没设；设了就在「我的」页页头代替用户名，没设头像时首字母也取自昵称**（选定）。管理端右上角仍显示用户名，用户列表加一列昵称。

**改用户名**

- **不让改**：否——主人明确要能改。
- **规则同注册，要输入当前密码，改完旧名立刻释放，当前设备保持登录，次数不限**（选定）。登录令牌里存的是用户 id，所以改名不会让任何设备掉线。

**改密码**

- **改完只换本机的令牌，其他设备照常登录**：否——改密码多半是怀疑密码泄露了，旧令牌签发后 7 天内都有效，不收回等于白改。
- **要输入旧密码；改完其他设备全部下线，当前设备拿新令牌保持登录**（选定）。为此给每个用户加一个令牌版本号：改密时加一，校验令牌时版本对不上就拒绝。外部 agent 令牌是另一套凭证，不受影响。

**注销账号**

- **先进 7 天冷静期，期间登录就撤销**：否——要多一套「待删除」状态和到期任务，对一个人用的工具不值。
- **注销后数据进回收站**：否——账号都没了，回收站也跟着没了。
- **输入密码，再手打一遍用户名确认，然后立刻彻底删除全部数据和图片文件**（选定）。管理员账号也可以注销。

## Consequences

- 用户表新增昵称和令牌版本号两项；头像相关的数据见 ADR 0051。
- 校验登录令牌要多读一次用户行（读出令牌版本号）。账号注销后读不到这一行，旧令牌自然失效。
- 注销会删掉这个用户在所有表里的数据（含回收站和 agent 令牌）以及磁盘上的全部图片文件，用户名随之释放。页面上要写明：服务器备份里最多还会留 30 天（[ADR 0026](./0026-photo-storage-and-backup.md)）。
- 前端的日记草稿和数据缓存原来按用户名区分，改用户名后会对不上，没发出去的日记草稿会丢。所以要改成按用户 id 区分。
- 找回密码、验证码风控、注册限流仍然不做：忘记密码还是只能改数据库。
