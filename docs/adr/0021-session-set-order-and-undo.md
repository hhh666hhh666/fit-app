# 会话页组内顺序推进与组次删除、取消完成

Status: accepted

需求要求「前面的组次没完成不能勾后面的」（越级点勾直接没反应、不弹提示），并要求训练中能删掉多余的组次、能取消已经勾上的组。现状两处都不满足：同一个动作里**任何**未完成的行都能点勾（[ADR 0010](./0010-session-free-switch-and-early-finish.md) 引入的动作自由切换把「组」这一层也放开了），而已经勾上的组点不动、无法回退。

## Considered Options

- **全局严格顺序**（A 动作的组全部做完才轮到 B）：否——[ADR 0010](./0010-session-free-switch-and-early-finish.md) 已经明确否过一次（器械被占先换下一个动作是真实习惯），那条理由现在依然成立。
- **不约束、保持现状**：否——需求就是要这个约束，不改等于没做。
- **越级点勾弹一句提示**：否——需求明确「不用提醒，直接没反应就行」。
- **顺序约束做成实时计算**（后面不满足条件的行显示为禁用）：否——页面上会同时出现「已完成」与「禁用」两种状态，反而要说清两者区别；静默无效更省事也更符合需求。
- **取消勾选只取消这一组**：否——会留下「第 2 组空着、第 3 组却打着勾」的矛盾态，看到只会怀疑是不是漏记了。
- **行尾常驻删除按钮**：否——与「勾」并排，正想按勾却按成删，误触代价是丢数据。
- **只约束同一动作内 ＋ 越级点勾静默无效 ＋ 长按组行弹操作菜单 ＋ 取消完成二次确认且级联取消该动作内后面已勾的组**（选定）。

## Consequences

- 动作之间的**自由切换**与「全组完成自动切到下一个未完成动作」都不变（[ADR 0010](./0010-session-free-switch-and-early-finish.md) 的主结论保留），收紧只发生在**组**这一层：同一个动作内第 1 组没勾，就不能勾第 3 组。
- 长按组行弹操作菜单：未勾的行只有「删除这一组」；已勾的行有「取消完成」与「删除这一组」。入口形态与日志页「长按进操作」的习惯一致，页面上不新增常驻按钮。
- 每个动作**至少留一行**：不能把某个动作的组全删空——那等于顺手把动作也删了，而主人未必想。
- 「已勾的组永远是连续的一段」成为该动作内的不变量；取消完成时弹窗要明说连带取消了后面几组。
- 删除或撤回都不影响计划的**目标组数**：三层目标只是预填默认值（[ADR 0007](./0007-session-set-flow-and-target-weight.md)）。
- [会话页临场编辑能力待办](../todo/2026-10-12-TODO-会话页临场编辑能力.md) 里的「组级撤回」一项由此落地，该待办收窄为「添加计划外动作」与「换成任意动作」两项。
