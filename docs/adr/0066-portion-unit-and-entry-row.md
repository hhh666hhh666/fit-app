# 常用份改成「单位 ＋ 一个多少 g」，条目行改用食物列表行样式并显示食物图片

Status: accepted · 2026-11-23

常用份原来存一段自由填的「份标签」（如「1个」），记一餐时的切换按钮却一律写「份」，填了「个」也看不到（2026-11-23 主人反馈）。改成份标签只存**单位**（「个」「碗」…），编辑页给一排常用单位点选、也能自己打字；份量行、提示和「这一餐」的条目行都按这个单位显示。条目行同时改成和食物列表同一种行。

## 决策

1. **份标签只存单位**：常用单位 份、个、只、颗、粒、片、块、根、条、串、张、碗、杯、盘、盒、袋、包、瓶、勺，外加自定义；没设常用份时默认「个」。
2. **老数据迁移**：开头是「1」或「一」的去掉（「1个」→「个」）；开头是别的数字的，连克数一起换算（「2片 30g」→「片 15g」）；其余认不出来的改成「份」，克数不动。
3. **条目冻结单位与一份克数**：按份记的条目记下当时的单位和一份多少 g，行里显示「10 个（208.3g）」；以后改了食物的常用份，老记录的个数不变（同「被记录引用时按快照冻结」）。
4. **条目行用食物列表行的样式**：缩略图 ／ 名字＋标签 ／ 份量·时刻 ／ 三大营养素，右边大卡；早午晚餐的时刻整餐共用，行里不重复。长按多选、点一下弹菜单不变。
5. **条目行显示食物图片**：修订 ADR 0057「饮食记录里也不显示」——记录行里显示，没图显示占位；拍照记录仍是另一回事。
6. **同批：吃过的临时条目可以从记一餐列表移除**：长按那一行 →「从列表移除」→ 确认。只是不再列出，以前记过它的餐不动、热量不变；移除之后又记了一模一样（同名同营养）的一条，它会重新出现。

## Considered Options

- **份标签保持自由文字，显示时从里面抽单位**（第一轮推荐的方案甲）：否。主人要的是「设了什么单位就显示什么」，从「2片」「1袋(50g)」里抽不干净，不如在源头只存单位。
- **老数据一律改成「份」**：否。大部分是「1个」这种，能原样保住单位。
- **条目行按食物当前的一份克数现算个数**：否。改一次常用份，过去的记录全跟着变。
- **只借列表行排版、不放图**：否。主人要的就是搜索列表那种样子，图是其中最显眼的部分。
- **移除临时条目＝连同记过它的条目一起删**：否。会改掉历史热量；单条条目本来就能在「这一餐」里删。

## Consequences

- 迁移 V50 只改**自建**食物的份标签；预置行按 ADR 0049 不动，显示时由前端 `portionUnit()` 去掉开头的 1 / 一。管理端的字段改叫「单位」，没有点选，照填单位即可。
- 迁移规则是按通用写法定的，没对过线上真实数据；认不出来的退回「份」、克数不动，热量不会算错，最坏是单位不如原来贴切，可在编辑页重选。
- 标签识别读到「每份 xx g」时，常用份的单位填「份」。
- `meal_log` 多两列、`meal_pick_hidden` 新表（注销时按 user_id 删）；条目返回多带单位快照与来源食物的图片、生熟。
