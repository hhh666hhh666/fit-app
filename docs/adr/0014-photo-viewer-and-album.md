# 照片浏览：自写全屏看图浮层与相册页

Status: accepted

照片的浏览分两处——记录弹层里点一张、以及「我的」页新增的相册页。此前唯一的行为是"点图即重新选图"：既看不了大图，又容易误触覆盖原图。本卡让两处共用一套全屏看图能力，并把相册页做出来。

## Considered Options

- **用系统级 `uni.previewImage`**：否——H5 端各浏览器的缩放能力不一致，且不可自定义（加不了删除，也统一不了外观）。
- **点图仍是"重新选图"（维持现状）**：否——最常用的动作是"看拍得对不对"，一点就换会让误触直接覆盖原图。
- **相册按月折叠**：否——照片目前只有十几张，折叠多一次点击却没有收益。
- **相册纯网格不分组**：否——丢掉日期这条唯一的定位线索。
- **相册只读、删除回饮食记录里做**：否——把"哪张属于哪天哪一餐"的记账负担丢给了主人。
- **自写全屏看图浮层 ＋ 相册网格（每行 3 张、日期分组）＋ 左右滑翻页 ＋ 就地删除**（选定）。

## Consequences

- 新增公共组件「全屏看图浮层」，接受**单张**或**列表 ＋ 当前索引**两种入参：记录弹层传单张、相册传列表，从而支持左右滑翻页。
- 手势分工：**单指左右滑 ＝ 翻页、双指 ＝ 缩放**，两者不冲突（与 [ADR 0015](./0015-diet-trend-zoomable-timeline.md) 的趋势图分工同一思路）。浮层内另有双击放大、上下滑关闭与右上角关闭键。
- 记录弹层里照片的显示改为**按原图比例自适应、不裁切、限高**（现状是固定高度裁切，竖拍的餐盘会被拦腰切）；点图进全屏，图片角上浮「更换」「删除」两个按钮。
- 相册页：照抄食物库页的触底分页写法；缩略图懒加载，每张用完必须释放 blob。
- 入口：「我的」页照抄现有条目加一栏，右侧显示照片张数。
- 相册里点开大图可直接删除（走 [ADR 0013](./0013-photo-storage-and-quota.md) 的删除接口与二次确认）。
- 不做「从照片跳到当天饮食记录」——相册只管看照片，要看记录去「饮食」页翻。
