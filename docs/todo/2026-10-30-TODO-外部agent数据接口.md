# 待办：外部 agent 数据接口

创建：2026-10-30 · 状态：待办 · 优先级：低

## 背景

接口已实现（[ADR 0043](../adr/0043-external-agent-read-api.md)），历史接口不设时间上限。本机用 5 年合成数据实测过，后端内存没有问题，结果记在 ADR 里。还没验证的是生产：MySQL 与 quizzy 共用，内存紧张，[备份时被 OOM 过](./2026-10-19-TODO-备份时MySQL被OOM.md)，全量拉取会不会加重它，本机测不出来。

## 可选方案

上线后，等真实数据积累起来，或 agent 开始定时拉取时，观察 MySQL 内存和全量拉取耗时：

- **方案甲：没有影响，保持不设上限** —— 代价：无。
- **方案乙：影响到 MySQL，按日期分块或限制并发** —— 代价：接口多一个续拉字段，agent 要循环拉取。

➡️ 倾向：方案甲。全量查询是分批的，单用户频率也很低；真有影响再走乙。
