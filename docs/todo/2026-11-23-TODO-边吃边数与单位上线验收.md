# 待办：边吃边数与单位上线验收

创建：2026-11-23 · 状态：待办 · 优先级：中

## 背景

边吃边数（[ADR 0067](../adr/0067-eat-and-count.md)）、常用份单位与条目行（[ADR 0066](../adr/0066-portion-unit-and-entry-row.md)）、App 内更新日志（[ADR 0068](../adr/0068-in-app-changelog.md)）和「键盘弹起藏贴底件」都只在电脑浏览器里按手机宽度验过。有几件事只能在真机或线上做：

1. **安卓壳里键盘弹起**：本机是靠缩窗口模拟的，壳里 `adjustResize` 时可视高度是不是真的变矮、贴底件有没有藏干净（特别是会话页的汇总条和底栏），没有真机看过。
2. **震动与长按**：边吃边数的轻震（`tickCount`／`tickTen`）、长按餐次入口进计数，要在手机上点一遍。
3. **线上份标签迁移**：V50 的迁移规则没对过线上真实数据（本机 SSH 查库被拦）。发版后在编辑页翻几条自建食物，看单位是否合理。
4. **管理员的开发细节开关**：本机账号不是管理员，更新日志页右上角的开关没点到过。
5. **DESIGN.md 快照没重新生成**：新增了 `$count-hues`、`$meal-count-*` 两组 token 和 `hide-on-keyboard` mixin，`DESIGN.md` 是从实现派生的快照，按规矩该重新生成，不手改。

## 可选方案

- **方案甲**：发版后主人在手机上按上面 1–4 走一遍，有问题再开修复；DESIGN.md 下次动设计系统时一起重新生成 —— 代价：问题要等发版后才暴露。
- **方案乙**：发版前先用 `scripts/build-apk-web.sh` 打一份本地包装到手机上验 —— 代价：多一轮打包安装。

➡️ 倾向：甲。改动都在 H5，发版后自动更新就能在手机上看到，出了问题回滚也快；DESIGN.md 不影响运行。
