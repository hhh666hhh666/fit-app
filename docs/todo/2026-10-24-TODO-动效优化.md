# 待办：动效优化

创建：2026-10-24 · 状态：待办 · 优先级：中

## 背景

对全站动效做了一次评估（impeccable critique，快照 `.impeccable/critique/2026-10-24T14-54-00Z__frontend-src.md`，动效视角 25/36）。切页（[ADR 0040](../adr/0040-tab-slide-clone-layer.md) 的克隆层）已经做到真机上限：实测点击后约 40ms 两页同帧起跑，指示条跨格，三者共用 `$dur-slide` 与 `$ease-out`；动效 token 全站引用，`prefers-reduced-motion` 每个动效组件都有降级。问题集中在切页以外。

## 发现的问题（按严重度）

1. **[P1] 「完成一组」没有回执**（`pages/session/index.vue`）：点 ✓ 后当前行瞬间变只读、高亮跳下一行；一个动作做完整张卡瞬间换成下一个动作，只有轻提示「进入下一动作：…」；最后一组只有轻提示。组间单手、眼睛不在屏幕上时，会再瞄一眼确认，换动作没察觉还可能对着新动作填旧重量。
2. **[P2] 弹层退出两套**：`FtSheet` 用户关（遮罩／关闭钮／下拉／返回键）播 220ms 退出，保存成功由父组件 `v-if` 关则瞬间消失；`MealSheet`（首页最高频）、`ComboEditSheet`、`PhotoViewer` 一律瞬间消失（实测约 11ms）。退出还沿用进入的快出缓收曲线。
3. **[P2] 二级页硬切**：`navigateTo` 进出零动画，和主 tab 之间的方向横移落差大，层级关系没表达。
4. **[P2] 按压反馈 55 处 7 种写法**：`opacity` 0.6／0.7／0.75／0.8、`scale` 0.93／0.94／0.97、底色变化；约一半没有过渡。

次要：`reduced-motion` 下 `FtSheet` 关闭后透明遮罩仍挡 220ms、吞点击；`uni-modal` 自带 250ms `ease` 淡入，与 token 不一致；下拉关闭只认 120px 距离不认甩动速度；5 个页面各写一遍 `.seg__item` 的降级，应收进 `seg-item` mixin。顺带（非动效）：会话页当前行的单位字 `#6e6e73` 在 `#fcede3` 上对比度 4.4:1，差一点到 4.5。

## 可选方案

- **方案甲：只统一**——2、4 两条加次要项：抽「退出再卸载」共用逻辑、三个自写弹层接上、保存走同一路径、退出 180ms 加速曲线（`uni.scss` 加 `$ease-in`）；加 `press` mixin（变暗 0.7／收缩 0.96／底色，按下即时、松开 150ms）替换 55 处。不碰会话页与导航层。
- **方案乙：统一 ＋ 会话页回执**——甲的全部，再加 1：勾 150ms 从 0.6 倍弹入、刚完成行橙底 220ms 退白、高亮下滑；换动作卡片按方向横移（复用切页曲线），动作条选中项同步。
- **方案丙：乙 ＋ 二级页推入**——再加 3：二级页只播入场（正文自右 24px ＋ 淡入 220ms），返回不播，`FtPageHeader` 不动。

➡️ 倾向：方案乙。P1 直接关系「组间 30 秒记一组」的主动线；二级页推入碰导航层、收益是观感，可以等乙落地后再看要不要。

## 已定（2026-10-24）

主人选：**方案丙**（统一 ＋ 会话页回执 ＋ 二级页推入），完成一组**加短震动**，打破 PR 的那一组**回执不一样**。

落地时要注意：

- **震动**：壳的 `AndroidManifest.xml` 目前只有 `INTERNET`，要加 `android.permission.VIBRATE`，壳推到 7／0.1.6、重打 apk；H5 侧 `navigator.vibrate` 不存在或旧壳没权限时静默跳过。
- **PR 回执的基线**：会话页现在只有「上次」（`/workouts/last-record`），没有历史最重一组。口径按既定的 PR（重量最大、同重量比次数，有氧不参与）；基线要在进会话时取到（`/stats` 已返回 `prs`，先核对它是不是覆盖全部动作，不够就给 last-record 补字段），取不到就不提示 PR，**不拿推算值冒充**。
- **二级页推入**只播入场、返回不播（上一页保活在原地）；`FtPageHeader` 不动；`reduced-motion` 下不播。

## 真机反馈

- 2026-10-25：弹层滑进滑出「生硬、帧率很低」。原因是 0.28.0 让遮罩根元素动 `background-color`（整屏每帧主线程重绘）＋ 面板没有常驻图层；改成只动 opacity／transform、面板 `will-change: transform`，待再看一次。
- 同类风险：二级页推入动的是 `left`（每帧布局 ＋ 重绘），可能也掉帧——没改，等主人看真机再定（备选：只淡不滑，或改 transform 并另外处理 fixed 底栏）。
