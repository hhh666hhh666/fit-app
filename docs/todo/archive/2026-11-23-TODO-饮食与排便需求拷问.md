# 待办：饮食与排便需求拷问

创建：2026-11-23 · 状态：已解决 · 优先级：中

## 背景

主人一次提了七条，正在逐条拷问，还没拍板：

1. 饮水的时刻可以清除，清除后这一笔没有时刻。
2. 食物库「拍营养成分表」后的确认页：切到「每份」时会弹窗问一份多少，是否有必要。
3. 大便形态加「未知」；小便加颜色选项，选项旁带色块；一颗颗的大便算哪一型。
4. 记一餐时按份的快捷选项不该只有「1份」「×2」。
5. 一餐里的条目可以批量改时刻。
6. 食物列表按最后使用时间排序（现行排序见 ADR 0056：收藏 → 近 30 天记录次数 → 自建优先 → 名称）。
7. 食物列表每行显示碳水、蛋白、脂肪（参照主人给的截图样式）。

## 可选方案

各条的选项与推荐随拷问轮次给出，定下的结论落 ADR 与 `docs/requirements/scope.md`，这里只记还没定的。

### 第一轮已答（结论待全部定稿后落 ADR）

- 每份弹窗：乙＋丙。主人另报一个缺陷：编辑已有食物时切到「每份」改克重，下面的每份数不跟着变，保存后每 100 被改乱——要求改克重不动每 100。
- 大便「未知」：不加，没填就是未知，保持现状。
- 按份：选乙；按份默认 1 份、可改份数、显示总重；按重量时显示合多少份。
- 批量改时刻：只有加餐按条记时刻、可多选批量改；早午晚三餐每餐一个时刻。
- 生重 / 熟重：加这个属性，管理端手动赋值、可取消，没赋值不显示标签。「+」只在记一餐列表里，点「+」才记录，点食物进食物详情页。

### 第二轮已答

- Q1、Q6、Q10、Q11、Q15、Q17 按推荐；术语表已改「食物」「时刻」「排便记录」，新增「生重／熟重」。
- 常用份：先有每 100，再有份量；每份营养只由每 100 推算。包装只印了每份时，要先换成每 100 再填，然后填份量。
- 三餐一餐一个时刻（Q16 a–d 照做）。
- 记一餐列表：点「+」＝原来点食物（弹出份量行），点食物行进详情页。

### 第三轮已答

- Q16 全选（含 e：加餐多选批量改时刻 / 清除时刻）；Q19–Q21 按推荐：每份只读、详情页不加记录按钮、临时条目点行＝点「+」。
- 主人新提：列表里「预设」标签不好看，想换个区分预置与自建的办法；另查出界面写「预设」、术语表写「预置」，用词不统一。

### 第四轮已答

- Q23：统一叫「预置」（术语表「动作」一条已改）。
- Q22：预置不标，只标自定义；主人担心灰色不好看，已出四种样式对比图（灰字、浅橙字、灰图标、缩略图角上浅橙图标）。

### 第五轮已答

- Q24：选丁（缩略图右下角浅橙铅笔角标）；Q25：统一叫「自定义」（术语表已改）。
- 主人觉得列表行纵向三行太挤，已出两行排法对比图。

### 第六轮已答

- Q26：保持三行，但名字、份量、营养行整体缩小一号；主人觉得灰色「熟重」标签不好看，已出三种配色对比图。

### 第七轮已答

- Q27：选乙，生重浅绿、熟重暖褐。
