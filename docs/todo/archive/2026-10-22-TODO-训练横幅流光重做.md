# 待办：训练横幅流光重做

创建：2026-10-22 · 状态：已解决 · 优先级：低

## 背景

首页「训练进行中」横幅的边框流光是四层旋转圆盘：在扁长卡片上，光在长边中段慢爬、到转角猛甩（角速度匀速≠周长匀速），且四层父级 blur 每帧重算。试过 SVG 描边分段叠宽度的彗星（预览），真机效果是一节节方块：平头描边端点生硬、5 级宽度台阶明显、单位按周长百分比太粗（1 份≈8px）。主人要「比较精致的流星」，先出方案。

## 可选方案

- **方案甲：Canvas 逐帧画彗星**：横幅背后铺一块与卡片同尺寸（含外扩几 px）的 canvas，按 devicePixelRatio 放大；每帧沿圆角矩形周长取头部位置，尾巴切成几十小段，宽度与透明度沿长度连续衰减，头部一颗带小光晕的亮点；两颗相隔半圈对跑。只在页面可见时跑 rAF，`onHide` / 后台 / 减少动态效果时停在静态。—— 代价：要写一段周长参数化与绘制代码（约 100 行），尺寸变化要监听重算；canvas 不随 CSS 自动适配，要自己处理 DPR。
- **方案乙：`offset-path` 让一颗带渐变的小元素沿路径走**：头＋尾是一个短 div（线性渐变＋圆角），`offset-rotate: auto` 贴着切线。—— 代价：尾巴是刚体，过 12px 圆角时会切出卡片外；路径要按实际尺寸用 JS 拼。
- **方案丙：SVG 继续叠段，但改成 20+ 段、圆头、更细更短**。—— 代价：DOM 多、仍是台阶，只是更细；精致度上限低。

➡️ 倾向**方案甲**：只有它能做到宽度与透明度真正连续收尖、严格贴着圆角走、头部有柔和光点，而且画布很小、每帧几十段线，开销比现在的四层 blur 低。

## 待确认
