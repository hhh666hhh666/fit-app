# 待办：首页次数口径

创建：2026-10-16 · 状态：已解决 · 优先级：低

## 背景

首页统计条的「本周 X 次 / 本月 Y 次」原先是在前端过滤出来的：`home/index.vue` 的 `refreshCounts()` 拉 `listWorkouts(200)`（封顶 200 条）再按 `createdAt` 客户端分周／分月。记录一旦超过 200 条，这两个数字会**静默少算**——与 [ADR 0023](../../adr/0023-volume-metric-scope-and-display.md) 定下的「累计类数字必须走全量聚合」正面冲突。

## 落地结果

1. ✅ 后端按月概览接口（`GET /api/workouts/month-summary`）新增 `weekCount`（本周＝**周一 00:00 起**、跨度 7 天）；不传月份＝当月，首页正好一次拿全「本周 + 本月」。
2. ✅ 首页 `refreshCounts()` 改成调该接口，**客户端那段分周／分月过滤逻辑已删除**；首页请求数没变（少一次 200 条列表）。
3. ✅ 后端补测试：`monthSummary_readsCurrentPrevAndWeek` 断言三次查询的区间，其中本周按「是不是周一 ＋ 跨度 7 天」断言（不照抄实现里的算法）。

## 可选方案

- **复用现成的 `GET /api/stats?period=week|month`**：否——两次请求，且该接口会顺带算近 4 周柱状与 PR 归档，首页用不上的重查询。
- **让按月概览接口一并回本周次数**（选定）：一次轻量聚合拿全，不带多余计算。
- **不改**：否——记录过 200 条后首页数字长期少算，且这种错很隐蔽。
