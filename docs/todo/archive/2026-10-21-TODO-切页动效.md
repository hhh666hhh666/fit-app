# 待办：切页动效

创建：2026-10-21 · 状态：已解决 · 优先级：中

## 背景

主人反馈底部四个 tab 之间切换「太生硬」。硬约束不在 CSS 而在导航形态：四页走 `uni.reLaunch`，旧页在新页挂载前就已卸载，框架 `RouterView` 外层也没有 `<Transition>`——**DOM 上不存在新旧两页共存的时刻**，所以「A 滑出、B 滑入」的真推拉当场做不出来。

另外两条现状决定了改动位置：四页结构一致（`.xx` > `.xx__body` 含标题行 ＋ `.xx__bottom` 为 `position: fixed`），**给根元素加 `transform` 会让内部的 fixed 底栏改为相对根元素定位**，因此只能动 `__body` 一层；`frontend/src/uni.scss` 目前**没有任何动效维度**（duration / easing 皆无），全仓仅 4 处硬编码动效，`prefers-reduced-motion` 降级只在首页流光卡一处。

## 可选方案

- **方案 A｜单页淡入微移** —— `__body` 挂载时 `opacity 0→1` ＋ `translateY(8rpx)`，约 180ms。纯 CSS、零状态。代价：四个方向同一套，没有空间关系，只到「不是硬切」。
- **方案 B｜方向感知横移** —— `FtTabBar.go()` 记录当前页下标，新页按差值决定从右/从左入场（`translateX(±18vw)` ＋ `opacity .6→1`），`cubic-bezier(.22,.61,.36,1)`，220ms。代价：需跨页面重建传递方向（`reLaunch` 不重载 JS，Pinia 实例存活，可直接用 store，刷新时无 from 就走纯淡入兜底）；快速连点需时间戳 guard 挡方向错乱；旧页滑出仍看不到，靠方向一致＋底色骗眼。
- **方案 C｜壳页 ＋ 横向 track** —— 四页正文抽成组件横向排列，`translateX(-index × 100vw)`，四页真共存，可顺手加左右滑动手势与 `keep-alive`（滚动位置、日志月份一并解决）。代价：等于重写导航层——文档级滚动要改独立 `scroll-view`、下拉刷新自实现、`onShow` 取数语义重建、四页懒加载（各 10~26KB）变成首屏全量。
- **方案 D｜`tabBar` ＋ `switchTab` 保活** —— 走框架保活拿共存。代价：`switchTab` 协议无动画参数、`RouterView` 外仍无 Transition，想自定义横移得改框架；[ADR 0035](../../adr/0035-client-cache-and-invalidation.md) 已否过一次，H5 下自绘 tabBar ＋ `switchTab` 的保活行为未实测。

➡️ 倾向**方案 B**（2026-10-21 主人已口头选定，同日选定「底栏钉住不动」与「220ms」）。理由：四案中唯一不碰导航结构的，与 ADR 0035 的取舍、与 `docs/todo/archive/2026-10-21-TODO-切页体验后续.md` 倾向的方案甲同向；改动塌缩到 `FtTabBar` 一个函数 ＋ 四页各加一个 class ＋ `uni.scss` 三行变量。方案 C 上限最高但属「重做 tab 容器」级别，应单开一摊而非混入动效需求。
