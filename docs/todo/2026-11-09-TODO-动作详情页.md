# 待办：动作详情页

创建：2026-11-09 · 状态：待办 · 优先级：中

## 背景

动作库里点一个动作（浏览模式、未下架）目前只弹「动作详情建设中」。scope 承诺的「统计（PR／频次／趋势）」里，**单个动作的趋势**全站还没有地方看；统计页的 PR 归档行也点不进去。后端已有改自定义动作的 `PUT /api/exercises/{id}`，前端没有入口。

建议的定位：**「这个动作我练得怎么样」的复盘页**，不是动作百科。第一版内容：

1. 页头：名称、肌群、预设／自定义／已下架标签、记录口径
2. PR 卡：最重一组（重量×次数、日期），点进那次训练详情
3. 趋势：每次训练一个点，复用 `FtTrendChart`
4. 历史：按训练倒序，每条＝日期＋该动作各组，点进训练详情；触底分页
5. 小计：练过几次、首次／最近一次日期
6. 底栏操作：自定义＝改名／改肌群、删除；已下架预设＝把现在的「复制／删除」菜单挪进来；上架预设＝只读

后端补一个按动作取历史的只读接口（动作元信息＋PR＋逐次训练摘要；N=1 数据量小，可一次给全）；回收站里的训练不算；前端走 `workout` 缓存域。

## 可选方案

趋势画什么：

- **方案甲**：力量画每次的**最重一组重量**，爬楼画每次**总层数** —— 代价：看不出「同重量多做了几次」
- **方案乙**：画这个动作每次的**容量** —— 代价：组数多少会把曲线拉得乱跳，和 PR 口径不是一回事
- **方案丙**：甲乙都给，分段切换 —— 代价：多一套切换与空态

➡️ 倾向：甲。和 PR「最重一组」同一口径，scope #7 已明说不做估算 1RM；同重量的次数变化在历史列表里看得到。

个人备注（座椅档位、握距这类）：

- **方案甲**：第一版不做 —— 代价：器械参数仍靠脑子记
- **方案乙**：每人每动作一段自由文字 —— 代价：预设动作是共享行，备注得另开「用户×动作」表

➡️ 倾向：甲，先把复盘页做出来；真想要再单独排，不和图文要领绑在一起。

动作要领：✅ 2026-11-11 主人拍板用丙（文字＋动图），已实现，见 [ADR 0055](../adr/0055-exercise-dataset-and-media.md)。详情页现在有动图、练到哪里、动作要领；**复盘部分（上面的 1–5 条里的 PR、趋势、历史、小计）和底栏操作还没做**。

入口：

➡️ 倾向：第一版接动作库（浏览模式）、统计页 PR 行、训练详情页的动作块三处；会话页不加，免得训练中误跳走。
