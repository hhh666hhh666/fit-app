# 待办：发版流水线 Node 20 告警

创建：2026-11-23 · 状态：待办 · 优先级：低

## 背景

v0.43.0 的 Release 跑通了，但「镜像 · 构建并推送」带一条告警：`docker/setup-buildx-action@v3` 与 `docker/build-push-action@v6` 还按 Node 20 写，GitHub 已在强制用 Node 24 跑它们。现在照常能跑，等 GitHub 彻底移除 Node 20 兼容，这两步可能直接失败，发版就卡在推镜像。

同一 job 的「设 public 失败」告警是预期内的（`continue-on-error`，两个包早已公开，服务器能匿名拉），不用处理。

## 可选方案

- **方案甲**：把这两个 action 升到支持 Node 24 的新大版本，推一个只跑 CI 的提交、下次 tag 时看告警是否消失 —— 代价：大版本可能改参数名，要对照它们的 release notes 改 `release.yml`。
- **方案乙**：先不动，等告警变成报错再改 —— 代价：出事那次正好在发版，得临时走手工路径（见已归档的「GitHub 账号计费锁定」待办）。

➡️ 倾向：甲，找个不急着发版的时候顺手升。
