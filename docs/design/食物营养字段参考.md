# 食物营养字段参考（营养成分表）

> 来源：需求方提供（2026-10-12 饮食记录功能需求打磨收录）。
> 用途：饮食模块「食物」的**营养字段全集**——各字段的必填/选填边界与落库口径随实现定，以 `docs/design/数据模型.md` 为准。

## 一、基础表头字段（营养表固定列）

1. 项目
2. 每 100g / 每 100mL / 每份
3. NRV%（营养素参考值百分比）

## 二、强制标示营养素

1. 能量（kJ）
2. 蛋白质（g）
3. 脂肪（g）
4. 饱和脂肪酸（g）
5. 碳水化合物（g）
6. 糖（g）
7. 钠（mg）

## 三、脂类相关

## 八、本表之外的扩展字段

上面七类来自国标营养标签；下面这些**不在标签里**，是食物库自用的扩展，单列在此、别与正表混着看。
必填/选填边界与落库口径不写在这里，以 `docs/design/数据模型.md` 为准（同本文件开头那条约定）。

1. 升糖指数 GI（无单位）
   - 基准：**葡萄糖＝100**——不采用「白面包＝100」的数据表：两套基准混用会让数值整体偏差约 1.4 倍
   - 记录口径：一个食物一个值，不区分同种食物的烹饪/加工形态；也不按份量折算（那是升糖负荷，本库不存）
