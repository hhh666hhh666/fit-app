# 健身记录APP 功能规划

> **输入素材（2026-10-11 收录）**：需求打磨的原始功能规划稿，仅供追溯；**正式范围以 [`scope.md`](./scope.md) 为准**，本稿不随需求变更同步。

### 1. 训练记录模块（核心）

1. 自定义训练项目库
   - 预设动作：按胸背腿肩手臂腹部有氧分类，包含动作名称
   - 支持用户新增自定义动作（自己输入名字、选择肌群）
2. 组次录入
   - 力量训练：组数、次数、重量、休息时长
   - 有氧训练：类型（跑步/爬楼/跳绳）、时长、距离、心率、卡路里、层数、次数
3. 训练计划
   - 预设计划：暂不预设，但要留预设的空间
   - 用户自建计划：把动作按顺序编排，每次训练直接打开计划开始记录
4. 训练日志
   - 时间线展示所有历史训练，按日期查看
   - 单次训练汇总：本次训练肌群、总组数、总重量、时长

### 2. 基础数据统计

- 训练频次：每周训练几次、训练时长统计
- 动作个人记录：每个动作的历史重量，自动记录**个人最好成绩PR**
- 简单图表：近4周训练次数趋势图

### 3. 基础辅助

- 身体档案：记录体重、体围（胸/腰/臀/手臂），支持定期录入，查看变化曲线
- 个人主页：基础信息、训练年限、训练目标（增肌/减脂/维持）

### 4. 营养辅助

- 饮食记录：食物录入（照片，食物详情、克重）、热量、三大营养素（蛋白/碳水/脂肪）、建立各种食物营养成分表库、
- 目标设定：每日热量、蛋白质目标，统计摄入完成度

### 5. 其他功能

1. **离线记录**：可以离线保存，联网自动同步
2. **单位切换**：公斤/磅切换，厘米/英寸
3. **训练笔记**：长篇备注，记录感受、伤病、训练心得
4. **快捷小组件**：手机桌面小组件，一键开始训练、完成训练
5. **数据导入第三方**：接入手环/手表，自动同步心率、有氧时长
